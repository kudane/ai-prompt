1. **ตรวจแบบคนที่ต้องอนุมัติงานจริง**

> ช่วยตรวจงานชิ้นนี้ **[วางเนื้อหาหรือรายละเอียดงาน]** โดยรับบทเป็น **[ระบุตำแหน่ง เช่น ผู้จัดการฝ่ายการตลาด/ลูกค้า]** ที่มีมาตรฐานสูงและต้องตัดสินใจว่าจะอนุมัติให้เผยแพร่หรือส่งต่อได้หรือไม่ โดยอิงจากเกณฑ์ **[ระบุเกณฑ์สำคัญ เช่น ความถูกต้องตามกฎหมาย/ความน่าเชื่อถือ]** อย่าเพิ่งชมงานหรือบอกว่าโดยรวมดี ให้เริ่มจากการหาจุดที่ยังไม่ผ่านมาตรฐาน เช่น เนื้อหาไม่ชัด ข้อมูลไม่ครบ เหตุผลไม่แน่น หรือส่วนที่อาจทำให้ผู้อ่านเข้าใจผิด ระบุจุดที่ต้องแก้พร้อมเหตุผลและแนวทางปรับปรุง หากไม่มีปัญหาสำคัญ ให้บอกตามตรงโดยไม่พยายามสร้างข้อผิดพลาดขึ้นมา นำเสนอคำแนะนำในรูปแบบตารางเพื่อให้อ่านง่าย
> 
> 

2. **ตรวจหาจุดผิด ไม่ใช่แค่ตรวจคำผิด**

> ช่วยตรวจข้อความนี้ **[วางเนื้อหา]** ซึ่งเป็นเอกสารประเภท **[ระบุ เช่น เอกสารสัญญา / อีเมลแจ้งผู้บริหาร]** โดยแยกการตรวจเป็น 3 ด้าน ได้แก่ ความถูกต้องของภาษา ความสมเหตุสมผลของเนื้อหา และความสอดคล้องของข้อมูล ชี้ให้เห็นประโยคที่มีปัญหา อธิบายว่าผิดหรือไม่ชัดเจนตรงไหน และเสนอวิธีแก้ไข โดยแยกสิ่งที่ยืนยันได้ว่าผิดออกจากสิ่งที่ยังต้องตรวจสอบเพิ่มเติม อย่าแก้ไขเนื้อหาทั้งหมดโดยไม่จำเป็น
> 
> 

3. **ตรวจว่ามีอะไรสำคัญตกหล่นไปบ้าง**

> ช่วยตรวจงานนี้ **[วางเนื้อหา]** โดยเป้าหมายของงานคือ **[ระบุเป้าหมาย]** และกลุ่มเป้าหมายคือ **[ระบุผู้อ่านหรือผู้ใช้งาน]** วิเคราะห์ว่ามีข้อมูล คำอธิบาย ตัวอย่าง หรือประเด็นสำคัญอะไรที่ควรมีแต่ยังขาดไปบ้าง แยกสิ่งที่จำเป็นต้องเพิ่มออกจากสิ่งที่มีแล้วจะช่วยให้งานดีขึ้น พร้อมอธิบายว่าการขาดข้อมูลแต่ละส่วนส่งผลต่อความเข้าใจหรือการตัดสินใจของผู้อ่านอย่างไร สรุปผลเป็นข้อๆ
> 
> 

4. **ตรวจจากมุมคนอ่านที่ไม่รู้อะไรมาก่อน**

> ช่วยอ่านเนื้อหานี้ **[วางเนื้อหา]** ในมุมของผู้อ่านที่มีระดับความรู้พื้นฐานคือ **[ระบุระดับความรู้ เช่น ลูกค้าทั่วไปที่ไม่มีความรู้ด้านไอทีเลย]** ชี้ให้เห็นว่ามีตรงไหนที่อาจอ่านไม่เข้าใจ สับสน ต้องตีความเอง หรือมีคำถามที่เนื้อหายังไม่ได้ตอบ จากนั้นเสนอวิธีปรับให้เข้าใจง่ายขึ้น โดยรักษาความหมายและข้อมูลสำคัญเดิมไว้
> 
> 

5. **ตรวจหาช่องโหว่ของเหตุผลและข้อสรุป**

> ช่วยตรวจบทวิเคราะห์หรือข้อเสนอของฉัน **[วางเนื้อหา]** โดยสมมติฐานหลักหรือเป้าหมายข้อสรุปคือ **[ระบุสมมติฐานหรือเป้าหมาย]** เน้นหาจุดอ่อนของเหตุผล ข้อสรุปที่ยังไม่มีหลักฐานรองรับ สมมติฐานที่อาจไม่ถูกต้อง และข้อมูลที่ขัดแย้งกัน หากมีข้อสรุปที่กระโดดจากข้อมูลไปไกลเกินไป ให้ชี้ว่าขาดเหตุผลหรือหลักฐานตรงไหน พร้อมเสนอว่าต้องเพิ่มข้อมูลอะไรจึงจะทำให้ข้อสรุปน่าเชื่อถือขึ้น
> 
> 

6. **ตรวจแบบคนที่ไม่เห็นด้วยกับงานเรา (Devil's Advocate)**

> ช่วยรับบทเป็นคนที่มีมุมมองต่างจากผู้เขียน โดยมีความกังวลหลักเรื่อง **[ระบุข้อกังวล เช่น งบประมาณที่สูงเกินไป หรือความเสี่ยงในการทำงาน]** และกำลังพยายามหาจุดอ่อนของงานนี้ **[วางเนื้อหา]** วิเคราะห์ว่ามีประเด็นไหนที่อาจถูกตั้งคำถาม ถูกโต้แย้ง หรือทำให้คนไม่เชื่อถือ พร้อมยกตัวอย่างคำถามยากๆ ที่ผู้อ่าน หัวหน้า หรือลูกค้าอาจถาม และเสนอวิธีเตรียมคำตอบหรือปรับเนื้อหาให้รัดกุมขึ้น โดยไม่ต้องโต้แย้งในประเด็นที่ไม่มีเหตุผลรองรับ
> 
> 

7. **ตรวจแล้วจัดลำดับว่าควรแก้อะไรก่อน**

> ช่วยตรวจงานนี้ **[วางเนื้อหา]** และรวบรวมจุดที่ควรปรับปรุงทั้งหมด จากนั้นจัดลำดับความสำคัญโดยพิจารณาว่าปัญหาแต่ละจุดส่งผลต่อคุณภาพงานมากแค่ไหน โดยอิงจากเวลาที่มีจำกัดคือ **[ระบุเงื่อนไขเวลา เช่น มีเวลาแก้เพียง 1 ชั่วโมง]** แยกเป็นสิ่งที่ต้องแก้ก่อนส่งงาน สิ่งที่ควรแก้ถ้ามีเวลา และสิ่งที่เป็นเพียงข้อเสนอแนะเพิ่มเติม สำหรับแต่ละจุดให้ระบุตำแหน่งที่มีปัญหา เหตุผล และวิธีแก้ที่นำไปทำต่อได้ทันที นำเสนอในรูปแบบตารางหรือ Action Plan
>
